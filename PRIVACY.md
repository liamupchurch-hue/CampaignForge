# Privacy notes (community beta)

The project is designed to store project JSON and optional uploaded documents locally. There is no promise of audited security or a complete privacy/compliance certification. Third-party services are optional but may involve online downloads, API requests and data transfers. See [API_AND_DATA_NOTICE.md](API_AND_DATA_NOTICE.md).

No bug report should contain credentials, unpublished manuscripts, or other people's identifying information. If a log is necessary, redact account names, home directories, tokens, and content excerpts before posting.
