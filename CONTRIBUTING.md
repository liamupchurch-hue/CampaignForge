# Helping with Campaign Forge

Thank you for testing the community preview. You do not need to know Python to help. Open a **Bug report** for reproducible errors or a **Feature idea** to describe something that would improve campaign preparation.

**Please do not upload private campaigns or account information.** Use an invented example or redact the materials. Attach sanitized screenshots and the app version when useful. Never post API keys, secrets, payment details, personal information or copyrighted rulebooks.

To test locally: install Python 3.11+, run `start_windows.bat` on Windows, and use the bundled synthetic `examples/` data. Before changing code, open an Issue proposing the change. Small, focused pull requests with tests are preferred. This is a source-available testing release, not currently an open-source contribution program. Please open Issues for suggestions; do not submit source-code pull requests until the maintainer announces contribution terms.

Suggested test areas: Oracle provenance and project edits; paragraph and character-sheet import; keyboard accessibility; book outline ordering; Cartography prop scaling; local image-workflow integration; safe backups; clearer setup instructions.
