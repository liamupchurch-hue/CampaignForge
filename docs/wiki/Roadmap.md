# Roadmap: From Community Beta to a Finished Campaign Forge

This is an overview of our direction, **not a release schedule**. For verified items and detailed blockers, the authoritative tracker is the [Steam Ready Checklist](https://github.com/liamupchurch-hue/CampaignForge/blob/main/STEAM_READY_CHECKLIST.md).

## 1. Protect the campaigns people build

Before adding too many new features, we need dependable save/reopen behavior, clear error handling, safe project migrations, backup/restore, and portable handling of linked Archive assets. We also need to check larger campaigns and varied Windows setups.

## 2. Polish the creative workflow

Improve the everyday experience across Roster & Bestiary, Encounter Builder, Cartography, The Archives, and Book Architect. The goal is clear navigation, readable controls, responsive previews, better book structure, and useful map exports.

## 3. Make AI genuinely optional and easy to understand

Continue improving The Oracle and the experimental ComfyUI Art Studio. Priorities include accurate local model detection, a clear explanation of costs/privacy, understandable errors, reviewed edits, and support for additional image model families **only after compatible workflows are tested**.

The main application must continue to function with no local models and no cloud account.

## 4. Deliver a dependable Windows application

Move from Python source and `.bat` test launchers toward a tested Windows build that does not require users to install Python. Before publishing a binary broadly, complete dependency/license notices, privacy/security checks, installation and upgrade tests, and error diagnostics.

## 5. Prepare for wider distribution

Create truthful screenshots, updated help material, system requirements, appropriate branding, and practical support channels. Evaluate a future **Steam release** only when the application is reliable and the distribution requirements are met.

**Development spending policy:** We are keeping work at **$0 during development**. Paid Steam onboarding or other purchases are deferred until explicitly approved later.
