# Welcome to Campaign Forge

**Campaign Forge is a Windows-first creative workspace for tabletop role-playing game campaigns.** It brings campaign notes, characters, creatures, locations, encounters, maps, reference material, and book-building tools into one place.

Our aim is simple: **help a Game Master turn an idea into an organized, playable world—and eventually into a campaign book worth sharing.**

Campaign Forge is being developed with Dungeons & Dragons and Pathfinder-style campaigns in mind, but it is not an official product of either game. Its current rules support is incomplete, and you should check generated or imported statistics yourself.

## What you can do today

The public **v1.0.0 community beta** provides:

- **Campaign workspace:** create, edit, save, and reopen campaign projects.
- **The Archives:** keep manuscripts, reference material, and images together.
- **Roster & Bestiary:** organize characters and creatures, with optional combat information.
- **Encounter Builder:** reference characters and creatures during encounter planning.
- **Cartography:** work with map backgrounds, terrain, markers, props, and PNG exports.
- **Bind the Tome / Book Architect:** organize chapters, preview a book, and export PDFs.
- **The Oracle (optional):** use a separately installed local Ollama model, or an explicitly configured external API, for creative assistance.

There is also an **experimental v1.1.0 development branch** with a ComfyUI-connected Art Studio for image generation. It is **not part of the public v1.0.0 release**, and additional model families are still under test.

## Where we are heading

We want Campaign Forge to become a polished, self-contained Windows desktop application that a Game Master can install and use **without learning Python**. The long-term goal includes reliable backups and project portability, a stronger map creator, improved character and encounter workflows, optional local image and writing AI, polished PDF book production, and eventually a thoroughly tested Steam release.

**AI is optional—not a requirement for using the core editor.** We also intend to keep third-party model installs and costs transparent, rather than silently downloading large models or charging through a hidden service.
