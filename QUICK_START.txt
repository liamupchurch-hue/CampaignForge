WINDOWS SETUP
1. Install Python 3.11+ with the py launcher from python.org.
2. Extract the Campaign Forge source ZIP outside Program Files.
3. Run start_windows.bat and review the beta notice.
4. Save a new .campaign.json before making major changes.
5. Back up Archives separately. Keep old versions and saves.
