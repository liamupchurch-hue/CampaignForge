Campaign Forge v1.1.0-beta.1 — LOCAL COMFYUI ART STUDIO TEST BUILD

1. Extract this ZIP to a separate folder and back up your campaign JSON + Archives.
2. Double-click start_windows.bat (Windows; Python 3.11+ required for source launch).
3. Start Comfy Desktop separately. Confirm your SDXL Base 1.0 checkpoint is installed.
4. Open Cartography > Generate Image (ComfyUI) in Campaign Forge.
5. It will try local ports 8188 or 8000. Click Find / Connect and select the checkpoint.
6. Enter positive and negative prompts; Generate Image; approve the local request.
7. Preview the image, Save PNG or Add to The Archives.

This is SOURCE CODE, not a prebuilt Windows exe. For your OWN test executable,
run build_windows.bat after start_windows.bat and keep all files inside
dist\CampaignForge together. Do not redistribute binary before license/security audit.
No models, ComfyUI, GPU drivers, or cloud API keys are included.
Actual live Windows ComfyUI testing remains pending.
