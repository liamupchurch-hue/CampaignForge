# Optional AI API, billing, and data notice

**You do not need to configure cloud AI to use Campaign Forge's basic editors.** Local Ollama and ComfyUI are optional external applications.

### Cloud API costs

- An API key is **not** your ChatGPT password. A paid ChatGPT subscription does **not** automatically include OpenAI API credits. API usage may be billed separately according to the provider's current prices, account settings, and payment terms.
- Generating many responses, analyzing long documents, or repeated retries can increase token usage and costs. You are responsible for configuring spending alerts/limits where offered and monitoring the provider account.
- Downloading models, optional programs, or Python packages may consume substantial bandwidth/storage and incur charges from your internet provider, even when the model/software itself is free.
- The maintainers do not control third-party billing, service availability, outages, payment processing, or refund policies. To the extent permitted by law, they disclaim responsibility for resulting charges and losses.

### Privacy and local files

- Saved campaigns and Archives are intended to be handled locally, but this does not constitute a security guarantee. Backups, Windows logs, crash reports, and user-selected outputs can contain sensitive data.
- When a user explicitly enables cloud AI, text from prompts and approved project or reference excerpts **may be transmitted to the chosen provider**, subject to that provider's policies. Never send private material without checking the confirmation and provider terms.
- Local Ollama/ComfyUI processing is not the same as cloud processing, though their installers, model downloaders, or update services may access the internet. Review their settings and policies separately.
- Do not share API keys or their screenshots in issues, pull requests, sample projects, or diagnostic logs. If a key is exposed, revoke/rotate it with the provider immediately.

### Generated output

AI responses can fabricate lore, rules, references, or statistics. Source labels and application validations do not prove factual or mechanical correctness. Review outputs, character stats, published PDFs, and image rights before using or distributing them.

This preview does not guarantee an individual billing ceiling or an entirely offline environment when optional online features are enabled.
